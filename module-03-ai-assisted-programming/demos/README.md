# Module 3 — Demos

This folder contains facilitator notes and materials for the Module 3 demos.

## Demo 1: Laravel generation

**Purpose:** Show how to generate a complete Laravel Eloquent model, repository, and service from a simple spec, then refine iteratively.

**Materials:** `01-laravel-generation.md`

**Setup:** Access to AI chat tool (GitHub Copilot for Business or approved tool). Use synthetic examples only.

---

## Demo 2: Legacy code explanation

**Purpose:** Show how AI can explain legacy code (pre-framework PHP, procedural classes) and suggest modern equivalents.

**Materials:** `02-legacy-explanation.md` + `code-samples/LegacyUserBean.php`

**Setup:** Access to AI chat tool. Use synthetic legacy examples only (not real internal code).

---

## Demo 3: Refactoring with AI

**Purpose:** Show how to refactor verbose, procedural PHP to modern PHP 8.3 style using collections and type hints, with safety checks.

**Materials:** `03-refactoring.md` + `code-samples/User.php`

**Setup:** Access to AI chat tool. IDE for running Pest tests before/after refactoring.

---

## Demo 4: Unit test generation

**Purpose:** Show how to generate Pest/Mockery tests, run them, and refine when tests fail.

**Materials:** `04-unit-testing.md` + `code-samples/Book.php`

**Setup:** Access to AI chat tool. IDE with Pest and Mockery. Sample Laravel service method.

---

## Presenter notes

- Do **not** paste real proprietary code or internal APIs in public tools during the session.
- Use the sample code provided in each demo file (synthetic examples).
- If you cannot run live (e.g. no internet or policy), use pre-recorded screenshots or slide versions.
- Emphasize **review before paste** — always evaluate AI output.
- Show **iterative refinement** — first output may not be perfect.
